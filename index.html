Erwartetes Deliverable

Erstellt als Team einen verständlichen Report, ein Info-Poster oder eine Mini-Keynote. Euer Ergebnis muss diese 3 Punkte klären:

  • 1
    Der Ist-Zustand Was hattet ihr vor dem Ausführen erwartet (eure Hypothese)? Welcher Wert hätte eigentlich an das System übermittelt werden sollen und was gibt die IDE stattdessen aus? (Stichwort: Rückwärtsgang)
  • 2
    Root Cause (Die Ursache) Warum gibt das Programm einen falschen Wert aus, obwohl keine Fehlermeldung erscheint? Und warum führt das bei der Rakete zum Absturz?
    🔎 Im Code steckt ein Datentyp, der nicht im Skript steht. Findet ihn und recherchiert selbst: Was ist das für ein Typ und welche Grenzen hat er?
  • 3
    Der Patch (Die Lösung) Wie lautet der korrigierte Code? Wie sieht der richtige Cast oder Datentyp aus? Bedenkt auch: Was müsstet ihr tun, wenn das Legacy-System wirklich nur 16-Bit-Werte annehmen kann?
🚀 Schon fertig? Expertenaufgabe ▼

Java besitzt neben short noch einen zweiten Datentyp mit genau 16 Bit. Findet ihn heraus.

  • Passt 40001 in diesen Datentyp? Gebt den Wert einmal direkt und einmal mit (int) davor aus. Was fällt euch auf?
  • Vergleicht die Bitmuster beider 16-Bit-Typen, z.B. mit Integer.toBinaryString(...) (schaut auf die letzten 16 Stellen). Warum ist der eine Wert negativ und der andere nicht?
  • Wäre das ein guter Patch für die ESA? Testet auch eine negative Geschwindigkeit und einen größeren Faktor.
TERMINAL - Navigation.java 
// Horizontaler Geschwindigkeitswert (Referenz Ariane 4)
double vAriane4 = 8000.15;
// Ariane 5 ist in der Startphase ca. 5x schneller
int faktorAriane5 = 5;

// Aktuellen Geschwindigkeitswert berechnen
double vBerechnet = vAriane4 * faktorAriane5;

// Legacy-System erfordert 16-Bit Ganzzahl.
// + 0.5 rundet auf die naechste ganze Zahl
// (der Cast allein schneidet die Nachkommastellen nur ab).
short sensorWert = (short) (vBerechnet + 0.5); 

System.out.println("Uebertragener Wert: " + sensorWert);
/* ZUR INFO: Der Bordcomputer erwartet hier ca. 40000 */

Willkommen im Emergency QA-Team der ESA. Wir schreiben das Jahr 1996.

Vor wenigen Stunden ist unser Flug 501 (Ariane 5) genau 39 Sekunden nach dem Start explodiert. Ein Feuerball im Wert von rund 370 Millionen US-Dollar. Die Telemetrie zeigt völlig absurde Daten: Das System dachte plötzlich, die Rakete würde mit Höchstgeschwindigkeit rückwärts fliegen und hat sie beim Versuch gegenzusteuern zerrissen.

Wir haben ein Code-Fragment aus der Navigationseinheit der Blackbox geborgen. Euer Job als Junior-Entwickler: Findet den Bug, bevor der Code in die nächste Rakete geladen wird!
